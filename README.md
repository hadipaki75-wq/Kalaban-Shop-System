# Kalaban Shop Management System

### Python-Based Retail ERP & Accounting Platform

> A comprehensive retail management and accounting system developed for a real-world retail business.

---

## Overview

Kalaban Shop Management System is a complete retail management and accounting platform designed and developed for a real-world retail business.

The system provides an integrated solution for managing products, inventory, customers, invoices, accounting, installment payments, expenses, and financial reporting.

> **Note:** This repository is intended only as a project showcase.
> The source code is not publicly available because the software was developed for a private client.
