# Store Management System

## Overview

A comprehensive retail management and accounting system developed for a real-world retail business.

This project helps manage inventory, customers, accounting, invoices, expenses, installment payments, and financial reports.

> **Note:** This repository is a project showcase. The source code is not publicly available because it was developed for a private client.

---

## Features

- Customer Management
- Product Management
- Inventory Management
- Invoice Management
- Expense Management
- Installment Payments
- Profit & Loss Reports
- User Authentication
- User Roles
- Dashboard
- Reporting
